# Reisync

Синхронизированные субтитры и спектр-анализатор для Spotify в отдельном
консольном окне, стилизованном под интерфейсы NERV из «Евангелиона».

Скрипт следит за тем, что играет в Spotify, подтягивает текст песни с
[lrclib.net](https://lrclib.net) и показывает строки точно в такт — крупным
ASCII-артом, с эквалайзером по реальному звуку системы и braille-артом
персонажа в углу.

## Возможности

- **Синхронизированные субтитры** — LRC-текст с lrclib.net; если синхроверсии
  нет, обычный текст раскладывается по длительности трека равномерно.
  Пауза, перемотка и дрейф позиции отрабатываются на лету.
- **Эквалайзер по реальному звуку** — фоновый поток слушает системный вывод
  (WASAPI loopback), раскладывает его FFT по 24 логарифмическим полосам.
  Пока текста нет, окно рисует большой спектр-анализатор.
- **Темы оформления** — пять палитр по «Евангелиону», каждая со своим
  braille-артом персонажа.
- **NERV-антураж** — шапка MAGI LYRIC-SYNC, прогресс трека, статус-строка
  с SYNC RATE и PATTERN, заголовок трека TOIlet-шрифтом (кириллица
  поддерживается).
- **История прослушивания** — каждый трек дописывается в `history.log`.

## Требования

- **Windows** (WASAPI loopback, WinAPI для консольного окна)
- Python 3.10+
- Spotify-аккаунт и зарегистрированное приложение Spotify

Зависимости:

```
pip install -r requirements.txt
```

## Настройка

1. Создайте приложение на <https://developer.spotify.com/dashboard>.
2. В настройках приложения добавьте Redirect URI:
   `http://127.0.0.1:8888/callback`
3. Скопируйте `spotify_config.example.json` в `spotify_config.json`
   и впишите свои ключи:

   ```json
   {
     "client_id": "...",
     "client_secret": "...",
     "redirect_uri": "http://127.0.0.1:8888/callback"
   }
   ```

   Либо задайте переменные окружения `SPOTIPY_CLIENT_ID`,
   `SPOTIPY_CLIENT_SECRET`, `SPOTIPY_REDIRECT_URI`.
   `spotify_config.json` в git не попадает (см. `.gitignore`) —
   ключи остаются локально.

При первом запуске откроется браузер для авторизации; токен кэшируется в
`.spotify_token_cache`.

## Запуск

```
python main.py
```

Либо двойным кликом по `Reisync.bat` — он сам подхватит `.venv`, если
виртуальное окружение лежит рядом. Для запуска «как приложение» сделайте
ярлык на `Reisync.bat` (ПКМ → Отправить → Рабочий стол) и в свойствах
ярлыка поставьте «Окно» → «Свёрнутое в значок»: консоль с логами будет
сворачиваться в панель задач, а на экране останется только окно субтитров.

Основная консоль остаётся под логи, окно субтитров открывается отдельно и
закрепляется поверх остальных окон. Включите музыку в Spotify — остальное
произойдёт само.

## Темы

Тема выбирается константой `THEME` в начале `main.py` (поменяй и перезапусти):

| Тема    | Палитра                          | Персонаж          |
|---------|----------------------------------|-------------------|
| `nerv`  | оранжевый NERV, арт — синева Рей | Рей Аянами        |
| `eva01` | фиолетовый с зелёным             | Синдзи Икари      |
| `eva02` | красный, арт янтарный            | Аска Лэнгли       |
| `eva08` | розово-фиолетовый                | Мари Макинами     |
| `mass`  | белый, Dummy Plug                | Серийные Евы      |

Там же есть `SWAP_ACCENT` (`True`/`False`) — меняет местами две цветовые
семьи темы: интерфейс (шапка, название, прогресс) красится цветом арта,
а арт персонажа и текст песни — цветом интерфейса.

## Как устроено

```
main.py                    lyrics_console.py (дочерний процесс)
┌──────────────────────┐   ┌────────────────────────────────────┐
│ опрос Spotify (~3с)  │   │ отдельное консольное окно, ~20 FPS │
│ текст с lrclib.net   │──▶│ TITLE:/LYRIC:/EQ:/POS: через stdin │
│ FFT системного звука │   │ figlet-арт, эквалайзер, прогресс   │
└──────────────────────┘   └────────────────────────────────────┘
```

- `main.py` — опрос Spotify, загрузка текста, поток субтитров
  (показывает строку, когда позиция трека доходит до её таймкода),
  поток эквалайзера, запуск и питание окна субтитров командами.
- `lyrics_console.py` — рендер окна: темы, компоновка кадра, плавная
  анимация полос и прогресса. Тема передаётся аргументами
  `--theme <имя>` и `--swap-accent`.
- `theme_arts.py` — braille-арты персонажей.

Артефакты работы: `history.log` (история треков),
`.spotify_token_cache` (OAuth-токен).

## Замечания

- Шрифты заголовка — TOIlet-семейство (`mono9`/`smmono9`): обычные
  FIGlet-шрифты не содержат кириллицы и молча выдают мусор вместо
  русского текста.
- Громкость системы на эквалайзер не влияет: нормировка адаптивная,
  по бегущему максимуму каждой полосы.
- Если в Spotify ничего не играет, скрипт просто ждёт и проверяет снова
  каждые 5 секунд.
